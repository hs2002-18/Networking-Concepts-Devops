## What is Observability?

Observability helps understand system behavior.

---

# Three Pillars of Observability

| Pillar | Purpose |
|---|---|
| Metrics | Numerical monitoring |
| Logs | Event records |
| Traces | Request journey |

---

# Metrics

Examples:

- CPU usage
- Memory usage
- Request latency
- Error rate

---

# Logs

Examples:

```text
User login failed
Database timeout
```

---

# Traces

Show full request path.

Example:

```text
Frontend -> API -> Database
```

---

# Popular Observability Tools

| Tool | Purpose |
|---|---|
| Prometheus | Metrics |
| Grafana | Dashboards |
| Loki | Logs |
| Jaeger | Tracing |
| OpenTelemetry | Telemetry |
