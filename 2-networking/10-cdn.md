## What is CDN?

CDN caches content closer to users.

---

## Benefits

- Lower latency
- Faster delivery
- Reduced backend load
- DDoS protection

---

## Example Flow

```text
User
  ↓
Nearest CDN Edge
  ↓
Backend Server
```

---

## Common CDN Providers

- Cloudflare
- AWS CloudFront
- Akamai
- Fastly

---

## Content Cached by CDN

- Images
- CSS
- JavaScript
- Videos
- Static assets
