## TCP

TCP (Transmission Control Protocol) is reliable and connection-oriented.

Features:

- Ordered delivery
- Reliable communication
- Retransmissions
- Error checking

---

## TCP Handshake

TCP uses a 3-way handshake:

```text
SYN
SYN-ACK
ACK
```

---

## Common TCP Protocols

| Protocol | Port |
|---|---|
| HTTP | 80 |
| HTTPS | 443 |
| SSH | 22 |
| MySQL | 3306 |

---

## UDP

UDP (User Datagram Protocol) is lightweight and connectionless.

Features:

- Faster
- Less overhead
- No retransmissions
- No guaranteed delivery

---

## Common UDP Protocols

| Protocol | Port |
|---|---|
| DNS | 53 |
| DHCP | 67/68 |
| Streaming | Various |

---

## TCP vs UDP Comparison

| TCP | UDP |
|---|---|
| Reliable | Faster |
| Ordered | Unordered |
| Stateful | Stateless |
| Higher overhead | Lightweight |
