# VPN vs Direct Connect

| VPN | Direct Connect |
|---|---|
| Internet-based | Dedicated connection |
| Cheaper | Lower latency |
| Easier setup | More reliable |

# Common AWS Networking Problems

| Problem | Cause |
|---|---|
| EC2 unreachable | Security Group |
| No internet | Route table/NAT issue |
| DNS failure | Route 53 issue |
| ALB unhealthy | Health check failure |
| EKS pod communication failure | CNI issue |
