## What is Route 53?

AWS managed DNS service.

---

# Common Features

- Domain registration
- DNS management
- Health checks
- Routing policies

---

# Route 53 Routing Policies

| Policy | Purpose |
|---|---|
| Simple | Basic routing |
| Weighted | Traffic splitting |
| Failover | DR setup |
| Latency | Lowest latency |
| Geolocation | Region routing |
